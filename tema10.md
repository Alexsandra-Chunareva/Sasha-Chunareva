```python
@lru_cache(None)
def fibonacci(n):
```

```python
class SiteChecker:
    def __init__(self, func):
        print('> Класс SiteChecker метод __init__ успешный запуск')
        self.func = func
    def __call__(self):
        print('> Проверка перед запуском', self.func.__name__)
        self.func()
        print('> Проверка безопасного включения')
@SiteChecker
def site():
    print('Усердная работа сайта')
if __name__ == '__main__':
    print('>> Сайт запущен')
    site()
    print('>> Сайт выключен')
```

Метод __call__ позволяет вызывать объект класса как обычную функцию, при этом он выводит сообщения до и после вызова декорированной функции. ### Ответ: 
```python
from time import process_time

def time_decorator(func):
    def wrapper():
        start_time = process_time()
        result = func()
        end_time = process_time()
        print(f"\nВремя выполнения функции: {end_time - start_time} секунд")
        return result
    return wrapper

@time_decorator
def fibonacci():
    fib1 = fib2 = 1
    for i in range(2, 200):
        fib1, fib2 = fib2, fib1 + fib2
        print(fib2, end=' ')

if __name__ == "__main__":
    fibonacci()
```

Функция `fibonacci` генерирует и выводит числа Фибоначчи до 200-го элемента.

### Ответ: 
```python
class CallLogger:
    def __init__(self, func):
        self.func = func

    def __call__(self, *args, **kwargs):
        print(f"Вызов функции: {self.func.__name__}")
        result = self.func(*args, **kwargs)
        print(f"Результат: {result}\n")
        return result
@CallLogger
def reverse_string(s):
    return s[::-1]

@CallLogger
def multiply_by_ten(n):
    return n * 10

print("Тест 1: Переворот строки 'hello'")
reverse_string("hello")

print("Тест 2: Умножение числа 5 на 10")
multiply_by_ten(5)
```

Он применяется к двум функциям: `reverse_string` (переворачивает строку) и `multiply_by_ten` (умножает число на 10). В тестах демонстрируется их вызов с декорированием и выводом логов.

### №5. 
Создайте собственное исключение, которое будет использоваться в двух любых фрагментах кода. Исключения, которые использовались ранее в работе нельзя воссоздавать. Результатом выполнения задачи будет класс исключения, код к которому в двух местах используется это исключение, скрипт консоли с выполненной программой и подробные комментарии, которые будут описывать работу вашего кода.
### Ответ: 
```python
class InvalidOperationError(Exception):
    #исключение, возникающее при попытке выполнить недопустимую операцию."""
    def __init__(self, message="Операция не может быть выполнена."):
        super().__init__(message)
#проверка деления на ноль
def divide(a, b):
    if b == 0:
        raise InvalidOperationError("Деление на ноль невозможно.")
    return a / b
#проверка диапазона значений
def check_range(value, min_value=0, max_value=100):
    if value < min_value or value > max_value:
        raise InvalidOperationError(f"Значение {value} должно находиться в диапазоне от {min_value} до {max_value}.")
    return value

#тестирование нашего исключения
if __name__ == "__main__":
    #тестирование для деления
    try:
        result = divide(10, 0)
    except InvalidOperationError as e:
        print(e)
    #нормальное деление
    result = divide(50, 5)
    print(result)
    #тестирование проверки диапазона
    try:
        checked_value = check_range(-1)
    except InvalidOperationError as e:
        print(e)
    checked_value = check_range(75)
    print(checked_value)
```
![Меню]()

### Вывод: 
Код определяет пользовательское исключение `InvalidOperationError` для обработки ошибок при выполнении недопустимых операций. Реализованы две функции: `divide` (проверяет деление на ноль) и `check_range` (проверяет, находится ли значение в заданном диапазоне). При некорректных данных выбрасывается `InvalidOperationError`. В блоке `__main__` демонстрируется работа с этими функциями: обработка исключений и выполнение корректных операций.

# Общий вывод по теме:
Тема 10 посвящена декораторам и обработке исключений в Python. Декораторы — это мощный инструмент, позволяющий изменять поведение функций и классов без изменения их исходного кода. Они являются функциями высшего порядка, принимающими другую функцию в качестве аргумента и возвращающими обёрнутую функцию. Это дает возможность добавлять такие дополнительные функции, как логирование, кэширование или измерение времени выполнения, что делает код более гибким и удобным для поддержки. 

Отдельно рассматривается использование декораторов для классов, позволяющее расширять их функциональность путём добавления новых методов или атрибутов. В Python также доступно множество готовых декораторов из сторонних библиотек, что значительно упрощает разработку.

Исключения, в свою очередь, представляют собой способ обработки ошибок, позволяющий контролировать и управлять ошибками, возникающими во время выполнения программы. С помощью блоков `try-except` разработчики могут обрабатывать исключения, предотвращая аварийное завершение программы и обеспечивая её стабильную работу.
